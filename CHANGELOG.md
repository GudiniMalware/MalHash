# Changelog

## 1.0.0

- Added an offline Python hashing core with bounded workers, cancellable scans, identity checks and optional file metadata.
- Added a headless CLI, a PySide6 desktop application and a documented Python API.
- Added cryptographic and fuzzy algorithms, PE import and Authenticode digests, and seven report formats.
- Added English, Russian and Spanish interfaces and text reports.
- Added native build and smoke-test scripts, PyPI-ready source and wheel packaging, and draft release automation.
